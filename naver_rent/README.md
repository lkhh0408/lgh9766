# 운정중앙역 전·월세 매물 수집기 (윈도우용)

네이버 부동산에서 **운정중앙역 반경 2km** 아파트의 전세·월세 매물을 모아 엑셀로 저장합니다.

- 보증금 3억 이하 / 월세 90만원 이하 / 전세·월세 모두
- 같은 매물(여러 부동산이 올린 동일 매물)은 하나로 합침
- 엑셀 열: 번호, 아파트 명, 세대 수, 주차 대 수, 평 수, 층 수, 방향, 보증금, 월세, 입주가능일, 중개사 이름, 휴대폰, 부동산 명, 링크(클릭하면 네이버 매물 화면)

## 1. Python 설치 (처음 한 번만)

1. https://www.python.org/downloads/ 에서 **Download Python** 버튼을 눌러 설치 파일을 받습니다.
2. 설치 첫 화면 아래쪽의 **"Add python.exe to PATH"** 에 반드시 체크한 뒤 **Install Now** 를 누릅니다.

## 2. 실행

1. `naver_rent.py` 와 `run.bat` 을 **같은 폴더**에 둡니다. (zip 파일이면 압축을 먼저 풉니다)
2. `run.bat` 을 더블클릭합니다.
   - "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행** 을 누릅니다.
   - 처음 실행할 때는 필요한 프로그램을 설치하느라 몇 분 걸립니다.
3. PC에 설치된 크롬(없으면 엣지)이 별도 창으로 열리고 네이버 부동산 단지 화면이 뜹니다. **창을 닫지 말고 그대로 두세요.** 검은 창에 진행 상황이 표시됩니다.
4. 끝나면 같은 폴더에 `운정중앙역_전월세_날짜_시간.xlsx` 파일이 생깁니다.

단지와 매물 수에 따라 10~30분 정도 걸릴 수 있습니다. 네이버 차단을 피하려고 일부러 천천히 조회합니다.

## 조건 바꾸기

`naver_rent.py` 를 메모장으로 열어 맨 위 "조건 설정" 부분의 숫자를 바꾸면 됩니다.

| 항목 | 기본값 |
|---|---|
| `RADIUS_KM` | 2.0 (km) |
| `MAX_DEPOSIT` | 30000 (만원, 3억) |
| `MAX_RENT` | 90 (만원) |

## 참고

- **평 수**: 공급면적을 평으로 환산했고, 괄호 안에 공급/전용면적(㎡)을 함께 적었습니다.
- **월세** 열: 전세 매물은 "전세"로 표시됩니다.
- **휴대폰**: 중개사 휴대폰이 없으면 사무소 대표번호를 넣습니다.
- 오류가 나거나 결과가 0건이면 검은 창 내용과 같은 폴더의 `debug_log.txt` 를 보내주세요.
