# 83타워 연속 비행 영상 — 1단계 분석 보고서 (이미지 연속성 + 제작 환경)

작성: 2026-10-13. 원본 137장은 읽기만 했고 수정하지 않았습니다. 모든 결과는 `work/` 아래에 있습니다.

## 0. 요약

- 137장은 목표한 시간 흐름(새벽 → 일출빛 → 낮 → 늦은오후 → 노을 → 해진 직후 → 야경)과 비행 흐름(원거리 접근 → 근접 → 선회 → 후퇴 → 야경 원경)을 **순서대로** 담고 있습니다. 순서를 바꿀 필요는 없습니다.
- 다만 이미지 자체에 영상화를 방해하는 구조 문제가 많습니다.
  - **정지 중복**: 인접 50쌍이 거의 같은 구도(정지처럼 보임).
  - **같은 장소를 다시 그린 듯한 배치 차이**: 23쌍(놀이공원·도로·산 능선·구름 배치가 바뀜).
  - **배경은 그대로인데 타워만 커지거나 작아짐**: 032~035, 067~070, 108~117, 122~126 (실제 카메라로는 불가능 → 합성 흔적으로 추정).
  - **타워 형태 차이**(전망대 층·첨탑 모양): 20쌍.
  - **완전 끊김**(대응점이 거의 없음): 050→051, 058→059→060, 110→111, 121→122.
  - **시간·조명 역행**: 005→006, 007→008, 102→103(노을색이 먼저 나옴), 105→106, 112→113, 123→124, 125→126.
- 그래서 137장 전부를 이어 쓰지 않고 **키프레임 59장 + 보정 후 사용 12장**을 고르고, 나머지는 색·구도 **참조 12장**과 **제외 54장**으로 정리했습니다(대응표: `image_roles.csv`).
- **제작 환경**: 이 작업 환경에는 GPU가 없고, 외부 영상 생성 서비스는 키가 없거나 네트워크가 막혀 있어 **지금은 영상 생성(시작·끝 프레임 지정)을 실행할 수 없습니다.** 실행에 필요한 조건은 6장에 정리했습니다.
