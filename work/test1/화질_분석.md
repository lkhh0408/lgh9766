# 화질 분석 — 생성 영상이 원본 이미지 화질에 못 미치는 이유

측정 스크립트: `work/scripts/quality_check.py`. 결과 표와 확대 비교 이미지는 `work/test1/quality/`에 있습니다.

## 측정 결과

| 대상 | 고주파 비중(%) | 비고 |
|---|---|---|
| 원본 008 / 011 / 013 | 5.6 / 7.4 / 6.5 | 선이 깔끔하고 명암 덩어리가 분명함 |
| T1 (깨끗한 키프레임 008ᶜ에서 시작) 1초 → 끝 | 8.6 → 15.6 | 클립 안에서도 점점 거칠어짐 |
| T2 (T1의 마지막 프레임에서 시작) 1초 / 끝 | 28.5 / 32.1 | T1의 약 2배. 나무 윤곽에 흰 테두리(헤일로)가 생김 |
| 같은 시작 프레임에서 Standard vs Fast(1초) | 29.2 vs 29.0 | 고급 모델도 차이 없음 |
| 720p 생성(T1_720) | 라플라시안 분산 264~365 (1080p는 1129~1816) | 헤일로는 없지만 흐림 |

- 고주파 비중: 원본 크기 스펙트럼에서 나이퀴스트 0.33 이상 구간 에너지의 비율입니다. 진짜 세부 묘사뿐 아니라 잡음·과샤프닝 테두리도 함께 커집니다.
- 재인코딩 손실(T1 프레임 기준 PSNR)
  - 편집본(CRF18): 41.6~42.7dB로 눈에 띄지 않는 수준
  - 대화창으로 보낸 27MB 사본: 33.5~37.2dB로 손실이 보일 수 있음
  - 처음 보낸 18MB 미리보기(CRF25): 손실이 더 큼

## 원인 (영향이 큰 순서)

1. **연쇄 생성에서 샤프닝이 쌓임**(측정과 확대 비교로 확인)
   - Veo 1080p 출력에는 경계를 강조하는 처리가 들어가 있습니다.
   - 그 출력의 마지막 프레임을 다음 클립의 시작 이미지로 넣으면, 이미 강조된 경계가 다시 강조되어 흰 테두리와 지렁이 같은 질감이 생깁니다.
   - 이 질감은 생성 단계에서 만들어진 것이라 후처리로는 거의 지워지지 않았습니다. 축소·확대, 양방향 필터, 노이즈 제거를 시험했고 고주파 비중이 30.9에서 최대 22.0까지만 줄었습니다(`quality/dehalo_test.jpg`).
2. **영상 모델은 프레임마다 그리지 않고 영상 전체를 한꺼번에 압축된 상태로 생성합니다.**
   - 그래서 나뭇잎·창문 같은 미세한 형태는 실제 모양 대신 질감으로 대충 채워집니다.
   - 원본 이미지는 나무 하나하나의 밝은 면과 그늘 면이 분명하지만, 영상은 잔 무늬가 많고 덩어리감이 약합니다(`quality/crop_park.jpg`).
3. **영상 압축**
   - Veo 결과 파일은 H.264 약 17~27Mbps입니다.
   - 나뭇잎처럼 세밀한 장면은 압축 손실이 큽니다.
   - 확인용으로 보낸 압축본은 손실이 더 큽니다.
4. **카메라 이동에 따른 움직임 흐림과 프레임마다 바뀌는 질감**
   - 정지 이미지에는 없는 요소입니다(재생 확인 필요).

## 대책 (본 제작에 반영할 것)

- **연쇄 입력 정리:** 앞 클립의 마지막 프레임을 그대로 넣지 않고, 720p로 줄인 깨끗한 버전을 다음 클립의 시작 이미지로 넣습니다. 출력 1080p는 그대로 둡니다.
  - 기대 효과: 강조 처리가 매번 한 번만 들어가 T1 수준이 유지됩니다.
  - 시험 1클립 약 $0.96이 필요합니다.
- **720p로 통일 생성 후 일괄 확대:** 모든 클립을 720p로 만들고 마지막에 같은 방식으로 1080p로 키웁니다.
  - 장점: 헤일로는 없고 클립 간 화질이 고르며, 연장 기능도 쓸 수 있습니다.
  - 단점: 더 부드럽습니다.
  - 확대 방식은 이 환경에서 쓸 수 있는 도구를 조사 중입니다.
- **고해상도 생성 후 축소:** Gemini API에서 4K가 되면, 4K로 만들어 1080p로 줄이면 더 깨끗할 가능성이 있습니다. 가능 여부와 가격은 조사 중입니다.
- **최종 파일은 CRF 16~18 이상으로 납품합니다.** 확인용 압축본으로 화질을 판단하지 않도록 원본 링크를 함께 드립니다.
- **Standard 모델은 화질 개선 효과가 측정되지 않았습니다.** 화질만을 이유로 쓰지 않습니다.
