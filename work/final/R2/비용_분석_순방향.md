# 순방향(역재생 없음) 재구성: 필요한 생성과 충전 금액 분석

작성일: 2026-10-20. 유료 생성은 아직 하지 않았습니다(360p 시험 제외). 금액은 모두 예상입니다.

## 1. 사용자 요구

1. 하늘로 올라가 하늘만 보여 주고 내려오는 장면(16~42.5초)을 **무조건 삭제**합니다.
2. 동선: 멀리서 자연스럽게 다가감 → 근접 → 회전 → 다시 멀어짐. **튀는 곳이나 속도가 바뀌는 곳이 없어야** 합니다.
3. 시간: 새벽부터 저녁·밤까지 **일정하게** 흘러야 합니다.
4. 역재생은 쓰지 않습니다.
5. 개인 비용이므로 꼭 필요한 만큼만 씁니다.

## 2. 왜 새로 만들어야 하는가

- 하늘 장면은 승인 1단계(0~16초, 놀이공원 언덕·회색 타워)와 중간 시험부터(아파트 도시·크림색 타워)의 세계·타워가 달라서 넣은 것입니다.
  - 그 바뀜을 가리려던 제 판단이었고, 사용자에게 먼저 묻지 않은 잘못입니다.
  - 하늘을 빼면 두 타워가 바로 맞붙어 컷이 됩니다.
- 이 모델은 첫 장면에서는 정확히 출발하지만, 정해 준 끝 장면에 정확히 도착하지 못합니다.
  - 착지 시도 3~4번이 모두 실패했습니다(겹쳐 보임, 순간 이동, 안테나 두 개).
  - 그래서 앞에서부터 순서대로 만들면 기존 조각(중간 시험, 멀어짐, 노을, 밤)에 이어 붙일 수 없습니다.
- 75초 창문 변화도 노을 조각을 다시 만들어야만 고칠 수 있습니다.
- **결론:** 한 세계(도시, 크림색 타워)에서 새벽 원경부터 밤까지 한 줄로 새로 만듭니다.
  - 시작 장면은 지금 영상의 밤 원경 프레임(도시 세계, 같은 타워)을 씁니다. 이미지 생성 비용이 들지 않습니다.
  - 동트기 전 어둠에서 출발하도록 지시합니다.

## 3. 오늘 360p 시험으로 확인한 것 (쓴 돈 $1.14, 승인 한도 안)

| 다시 시작할 때 | 앞 조각 끝 장면에서 다시 시작해도 같은 방향·같은 속도로 이어 돕니다(P1→P2). |

## 6. 돈을 지키는 장치

1. **관문 1 (360p 2개, 약 900원, 남은 한도 안):** 먼 곳에서의 새벽 접근 속도·빛, 노을·밤 후퇴를 확인합니다.
2. **관문 2 (4K 첫 묶음 A1 + A1e, 7,715원):** 큰 화면으로 승인본과 화질을 비교하고 속도를 잽니다. 결과를 보고드리고, **확인을 받은 뒤에만** 나머지를 진행합니다.
3. **조각마다 받자마자 확인하는 것**
   - 속도(이웃 9프레임 평균의 0.8~1.25배 안)
   - 선회 방향
   - 전망대 확대 비교(창 줄 수·모양)
   - 빛 변화(1초 안에 몰리지 않는지)

   불합격한 조각만 재시도 예산 안에서 다시 만듭니다.
4. **재시도 예산을 다 쓰면** 멈추고 보고합니다. 승인 금액을 넘는 생성은 하지 않습니다.
5. **서버 거절:** 응답에 '청구하지 않음'이 적힌 거절은 비용이 없습니다. 미확정은 결제 화면 확인을 부탁드립니다.
6. **이음새:** 다시 시작하는 지점은 타워가 작게 보이거나 움직임이 일정한 곳에 둡니다. 동작 전환(다가감 → 선회, 선회 → 후퇴)은 조각 안에서 6~8초에 걸쳐 일어나게 합니다.
