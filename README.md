# Open to Close

하루의 시작과 끝을 음악으로. YouTube 음악 채널 [@OpentoClose_day](https://www.youtube.com/@OpentoClose_day) 작업 저장소예요.

| 폴더 | 내용 |
|---|---|
| `docs/` | 제작 프로세스 가이드 PDF |
| `studio/` | 곡 폴더를 넣으면 캐릭터가 걸어가는 플레이리스트 영상을 만드는 도구 ([사용법](studio/README.md)) |
| `branding/` | 채널 배너, 프로필, 워터마크, 로고 |
| `thumbnails/` | 영상별 썸네일 (`vol01.png` 등) |
| `suno/` | Suno 곡 기록 (프롬프트 규칙, 만든 곡 목록) |
