# 바닷가 자전거 (PLAY LIST 03 후보, 진행 중)

- `sea.py`: 첫 시안(의상 3가지 + 낮·노을·밤). 의상 목록 `OPTS`와 `haru_bike`를 다른 파일이 가져다 써요.
- `sea2.py`: 디테일을 더한 해안도로 배경 `scene(ctx, 'day'|'dusk'|'night', scroll, t)`. 하늘(열기구, 배너 비행기, 갈매기), 언덕과 풍력 발전기, 바다(등대, 여객선, 요트, 윈드서핑, 부표), 해변(파라솔, 모래성, 비치발리볼, 망루, 강아지), 산책로(야자수, 아이스크림 트럭, 서프 숍, 벤치, 버스 정류장), 가로등, 꽃 덤불.
- `bike_test.py`: 35초 테스트. 의상 1(코랄 니트 + 네이비 머플러, 레몬 헤드폰, 민트 안전모) + 네이비 자전거. 오프닝(헤드폰 → ▶ → 안전모) → 낮은 선글라스 → 빨간불에서 멈춰 탭, 선글라스를 안전모 위로 → 초록불에 출발, 노을 → 밤 → 멈춰서 헤드폰 벗기.
- 음원은 scratchpad의 `vol03_songs/`에서 읽어요. 확정되면 render_video.py에 연결해요.
- `mix_test.py` (+ `bike_test_lib.py`): 41초 테스트. 낮 자전거 → (자전거 세우고 안전모는 핸들에, 선글라스는 머리 위로, 걸어가서 오픈카 탑승, 탭) → 노을 오픈카(머플러 날림) → (차 세우고 내려서 탭) → 밤 걷기 → 헤드폰 벗기.
