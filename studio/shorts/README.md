# 쇼츠 만들기 (확정: A 시안, 전체 화면 확대)

1. `shorts.json`: 회차별로 곡 순서(i, 0부터), 구간(a~b초, 곡 안의 시간), 곡 제목, 문구 세 줄(마지막 줄 강조)
2. `overlay_gen.py` → `render_overlay.js`: 문구, NOW PLAYING 바, "▶ 1시간 전체 듣기"를 투명 PNG(1080×1920)로 만들어요
3. `make_frames.py VOL <render_video 인자>`: 영상 장면을 화면 글씨 없이 다시 그려서 하루 중심으로 세로 크롭, 오버레이를 얹어 무음 영상을 만들어요. 같은 실행에서 음량이 맞춰진 믹스(_mix.wav)도 생겨요
4. 믹스에서 같은 구간을 잘라 앞뒤 0.5초 페이드, AAC 384k twoloop으로 합쳐요

- 길이 25~32초, 후렴 직전부터 후렴 끝까지
- 분홍 빗금(유튜브 버튼, 설명 자리: 오른쪽 150px, 아래 330px)에는 글자를 넣지 않아요
- 업로드: 월, 수, 일 오후 5시. "관련 동영상"에 그 회차 1시간 영상을 걸어요
