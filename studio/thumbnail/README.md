# 썸네일 (확정 스타일, PLAY LIST 01/02부터)

- `sticker.py`: 하루 스티커 PNG (의상 이름으로 만들어요)
- `base_layout.py`: 공통 틀 (배경, 왼쪽 밝은 그라데이션, 🎧 PLAY LIST 0X, NOW PLAYING 플레이어 바, 오른쪽 스티커)
- `three_line.py`: 세 줄 문구로 빈 공간을 꽉 채우는 버전 (한 줄만 의상 포인트 색 박스로 강조)
- `drafts_pl01_pl02.py`: PLAY LIST 01/02 문구 시안 10개씩
- `render.js`: 헤드리스 Chromium(playwright-core)으로 HTML을 1280×720 PNG로 찍어요

경로는 작업할 때 썼던 임시 폴더 기준이라, 새 회차에서는 맨 위 경로(S)만 바꿔 써요.
배경은 그 회차 영상 장면을 하루와 화면 글씨 없이 뽑아서 1600×900으로 잘라 써요.
